# Sonar

رادار الكريبتو والتداول التجريبي — تطبيق للتابلت (أندرويد) وللماك.

**التحميل:** [أحدث نسخة](https://github.com/ashrafmenour-jpg/sonar-app/releases/latest)
- التابلت: `Sonar.apk`
- الماك: `Sonar-Mac.zip`

## إزاي بيشتغل
- `web/index.html` هي صفحة Sonar نفسها. التطبيقين بيقروا `web/version.json` كل 3 ساعات، ولو فيه نسخة أحدث بينزّلوها لوحدهم.
- `android/` تطبيق أندرويد (WebView + خدمة بتخليه شغال والشاشة مقفولة + تحديث تلقائي).
- `mac/` تطبيق ماك (نافذة WebKit + سيرفر محلي على 127.0.0.1:47817 عشان البيانات تفضل ثابتة + تحديث تلقائي).
- `.github/workflows/build.yml` بيبني التطبيقين على سيرفرات GitHub ويحطهم في Releases.

مفيش أي مفاتيح أو بيانات شخصية في المستودع ده: البيانات والمفاتيح بتفضل على الجهاز بس.
مش نصيحة مالية.

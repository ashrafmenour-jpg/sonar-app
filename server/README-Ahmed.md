# Sonar على سيرفر — تسليم لأحمد

**الفكرة:** Sonar واحد بس شغال 24 ساعة على السيرفر. أشرف بيفتحه من **الكمبيوتر (أي متصفح)** أو من **تطبيق Sonar** على التابلت/الماك — بيشوف نفس Sonar اللي على السيرفر لايف ويستخدمه عادي (ضغط، سكرول، كتابة، أسئلة التأكيد، الملفات). مفيش حاجة بتشتغل على الجهاز، فمفيش عقلين ومفيش مزامنة.
**مفيش أوامر حقيقية** — Sonar مش بيبعت أوامر لأي منصة.

إزاي: نفس `web/index.html` شغال في Chromium headless على السيرفر. الشاشة بتتبث للمتصفح (JPEG عبر WebSocket) واللمس والكيبورد بيرجعوا للسيرفر (Chrome DevTools Protocol).

## 0) ارفع التحديثات على GitHub
Claude مش قادر يرفع من عنده. الـ commits جاهزة في `sonar-patches/` جوه الملف المضغوط:
```bash
git clone https://github.com/ashrafmenour-jpg/sonar-app.git && cd sonar-app
git am /path/to/sonar-patches/*.patch
git push origin main
```
بعد الـ push: تبويب **Actions** → «Test Sonar page» لازم يبقى ✅، و«Build Sonar apps» هيبني APK وتطبيق Mac جداد (فيهم خاصية فتح السيرفر جوه التطبيق). نزّلهم من **Releases** وركّبهم لأشرف مرة واحدة.

## 1) السيرفر
- VPS بـ **2 vCPU / 4 GB RAM** على الأقل، Ubuntu 24.04 (مثلاً Hetzner CX22 ~5 يورو/شهر، أو سيرفر Zeds نفسه لو فيه مكان).
- **مش في أمريكا:** Binance بيرفض الـ IPs الأمريكية (451). أوروبا كويسة.
- دومين فرعي: `sonar.zedsglobal.com` → A record على IP السيرفر (لازم HTTPS علشان التطبيق والكاميرا والـ WebSocket).

## 2) التركيب (~20 دقيقة)
```bash
apt update && apt install -y docker.io docker-compose-v2 git ufw
ufw allow 22 && ufw allow 80 && ufw allow 443 && ufw --force enable
git clone https://github.com/ashrafmenour-jpg/sonar-app.git /opt/sonar-app
cd /opt/sonar-app/server
cp .env.example .env && nano .env      # SONAR_PASS = باسورد طويل · READ_TOKEN = مفتاح قراءة بس (لـ Claude)
nano Caddyfile                          # sonar.example.com ← الدومين الحقيقي
mkdir -p data/import                    # ← ملف «كل بياناتي» من التابلت هنا قبل أول تشغيل (الخطوة 3)
docker compose up -d --build
docker compose logs -f sonar            # لازم تشوف: «Sonar اشتغل على السيرفر (نسخة …)»
```

## 3) نقل تعلّم أشرف (مرة واحدة)
1. من التابلت: المركز ← 📤 الملفات ← «📦 صدّر كل بياناتي».
2. الملف في `server/data/import/` ثم `docker compose restart sonar` → «اتنقلت بيانات التابلت (N جزء)».

## 4) أشرف بيفتحه إزاي
- **الكمبيوتر:** `https://sonar.zedsglobal.com` → الباسورد (بيفتكره 90 يوم). Sonar بيظهر بحجم الشاشة؛ الكيبورد والماوس والـ paste شغالين.
- **التطبيق (تابلت/ماك):** المركز ← **🌐 السيرفر** ← اكتب العنوان ← «افتح السيرفر». من بعدها التطبيق بيفتح على السيرفر على طول. زرار **📱** تحت بيرجّع لنسخة الجهاز لو احتاج. (التطبيقات القديمة هتفتحه في المتصفح لحد ما تتركّب النسخة الجديدة من الخطوة 0.)
- **تحت على الشمال:** 🟢 متصل · ⌨️ كيبورد (للمس) · 🔄 إعادة تحميل Sonar على السيرفر · 📊 حالة السيرفر.
- أي ملف Sonar بيحفظه (التشخيص، التعلم) بينزل على الجهاز اللي فاتح.

### وضعين
- **`/` ⚡ العرض السريع (الافتراضي):** Sonar نفسه بيشتغل في متصفح أشرف بسكرول عادي، ومتحمّل ببيانات السيرفر (التعلم والصفقات) ساعة الفتح. مش بيحفظ حاجة على الجهاز. بيتحدّث لما يرجع بعد 10 دقايق أو كل 30 دقيقة لو مش بيلمسه، أو بزرار 🔄. الصفقات الحقيقية بتتحوّل للوضع المباشر.
- **`/live` 🖥 الوضع المباشر:** شاشة Sonar اللي على السيرفر نفسه — للصفقات الحقيقية والإعدادات. أبطأ في السكرول.

## 5) لوحة الحالة `/status`
السيرفر شغال؟ · المنصات واصلة؟ · أخطاء آخر ساعة · مين فاتح · آخر الأحداث · تنزيل `/f/diagnosis` `/f/learning` `/f/all` `/f/errors`. و`/health` من غير باسورد للمراقبة.
**مفتاح القراءة (`READ_TOKEN`):** `…/status.json?k=<المفتاح>` و`…/f/diagnosis?k=<المفتاح>` بس — مش بيفتح Sonar ولا بيتحكم في حاجة. ده اللي يتدّى لـ Claude بدل الباسورد.

## 6) أوتوماتيك
- تحديثات من GitHub كل 20 دقيقة (لو `web/version.json` اتغيّر الصفحة بتتحمّل تاني).
- watchdog كل دقيقة؛ 3 نبضات فاشلة أو crash → المتصفح يقوم تاني. إعادة تشغيل يومية للذاكرة (مش وأشرف فاتح).
- `restart: unless-stopped` + healthcheck. البيانات في `data/profile`.
- كل 15 دقيقة: ملف تشخيص + ملف تعلم + نسخة كاملة؛ نسخة يومية في `data/backup/` لمدة 14 يوم.

## 7) المطلوب من أحمد بعد التركيب
1. UptimeRobot (مجاني) على `/health` كل 5 دقايق.
2. نسخ `data/backup/` لمكان تاني أسبوعيًا.
3. SSH بالمفاتيح بس، باسورد اللوحة طويل.
4. أول 48 ساعة: المنصات كلها ✅؟ الأخطاء قريبة من صفر؟ إعادة تشغيل المتصفح مش بتزيد؟
5. لو هيدّي Claude إمكانية يفحص بنفسه: الدومين لازم يتضاف في **claude.ai → Settings → Capabilities → allowed domains** (Claude شبكته مقفولة إلا على المسموح)، وأشرف يبعت لـ Claude `READ_TOKEN` بس.
